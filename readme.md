# 🎙️ Leo Frixi's Shell — RVC Models & Audio Tech Portfolio

Portafolio web interactivo y profesional desarrollado como proyecto para la academia **The Bridge**. La plataforma destaca el trabajo de ingeniería de voz con modelos **RVC (Retrieval-based Voice Conversion)**, la estructuración de datasets limpios y colaboraciones activas con creadores de la industria musical urbana e internacional.

## 🛠️ Tecnologías Utilizadas

### Frontend & Web Development

* **HTML5:** Estructura semántica multipágina (`index.html`, `portfolio.html`, `samples.html`, `biografia.html`, `contacto.html`).

* **CSS3:** Variables globales, layout híbrido en CSS Grid y Flexbox, efectos visuales *dark mode* con acentos verde neón (`#00ff88`).

* **JavaScript (ES6+):** Lógica modular para navegación entre pestañas de artistas y sistema de partículas interactivas de fondo.

### Audio & AI Engineering

* **RVC v2 (Retrieval-based Voice Conversion):** Entrenamiento e inferencia de modelos de voz.

* **Applio / Google Colab / Kaggle:** Entornos de ejecución y entrenamiento de redes neuronales.

## 🚀 Características Principales

1. **Catálogo de Lanzamientos:** Secciones dedicadas con reproductores integrados de YouTube para proyectos finalizados con productores y creadores.

2. **Galería de Muestras Crudas (Raw Outputs):** Disposición en cuadrícula responsiva (*grid layout*) con fotos editoriales de artistas y reproductores de audio nativos para que la calidad de los modelos hechos sea evaluable.

3. **Estructura Modular & Escalable:** Arquitectura lista para incluir nuevos colaboradores y samples sin alterar el diseño global.

4. **Diseño Tech / Cyberpunk Minimalista:** Interfaz optimizada para rendimiento y adaptabilidad a dispositivos móviles.
